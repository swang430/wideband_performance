# Welcome to UniCon

Universal Control (UniCon) is a pure, high-performance Hardware Abstraction Layer (HAL) for RF T&M instruments.

## 🚀 Live Demo
Experience the SCPI Playground and instrument mock API directly in your browser:
**[Launch UniCon Web Demo](https://swang430.github.io/wideband_performance/demo/)**

## Features

- Evidence-based driver development (SCPI references included)
- Robust PyVISA connections with exponential backoff
- Native Simulation Mode
- Asynchronous/Concurrent API support
