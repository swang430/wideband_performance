**重要关键词建议**：
- `switch`, `route`, `path` - 开关/路径控制
- `attenuation`, `attenuator` - 衰减器
- `amplifier`, `amp` - 放大器
- `relay` - 继电器
- `close`, `open`, `connect` - 连接/断开
- `query`, `state`, `status` - 状态查询

```python
def switch_rf_path(self, path: str) -> None:
    """
    切换射频通路（EMCenter 特定实现）。
    
    Ref: EMCenter TCU SCPI Manual, p.42 (Section 4.3 - Routing Commands)
    """
    if self.simulation_mode:
        self.logger.info(f"[模拟] EMCenter 切换RF通路: {path}")
        return
    
    # 根据手册实现 SCPI 指令
    self.write(f"ROUT:CLOSE '{path}'")  # ← 替换为实际指令
    self.logger.info(f"切换RF通路到: {path}")
```

**关键原则**（GEMINI.md - 硬件驱动开发铁律）：
