## EMCenter 系统架构

EMCenter 是一个**模块化插槽系统**，支持多种功能卡。手册中记录了以下模块：

| 模块型号 | 名称 | 功能 | 手册页码 |
|---------|------|------|---------|
| **7001-0xx** | EMSwitch | 射频开关控制 | p.8-14 |
| **7002-00x** | EMPower | 功率计/功率传感器 | p.15-28 |
| **7003-003** | EMGen | 信号发生器 | p.30-52 |
| **7006-001** | EMControl | 转台/定位器控制 | p.53-75 |
| **7007-200** | EMSense-10/40 | 电场探头/传感器 | p.76-82 |

- `get_relay_position()` ✅

## 2. EMPower (7002-00x) - 功率计 🆕 可扩展

### 功能

#### 功率测量
- 实时功率读取（dBm或W）
- 多点功率采样
- 峰值功率检测
- 功率偏移校准

#### 数据采集
- 可配置采样速度（1-5000 KS/sec）
- 缓冲区存储（多达10000个采样点）
- 触发采集模式

#### 工作模式
- 模式0: 连续测量
- 模式1: 单次测量
- 模式2: 自动存储
- 模式3: 突发(Burst)模式

### 主要SCPI指令

| 指令 | 功能 | 页码 |
|------|------|------|
| `<S>A:POWER?` | 读取端口A功率（dBm） | p.18 |
| `<S>A:BURST? <n>` | 连续测量n次功率 | p.16 |
| `<S>A:POWER_OFFSET <dB>` | 设置功率偏移 | p.19 |
| `<S>A:FREQUENCY <freq>` | 设置工作频率（Hz） | p.17 |
| `<S>A:FILTER <mode>` | 设置RMS滤波器 | p.16 |
| `<S>A:ACQ_SPEED <KS>` | 设置采样速度 | p.15 |

**EMCenter控制外部衰减器/放大器的可能性**: ❌  
- EMPower是**功率测量模块**，不能直接控制衰减器或放大器
- 但可用于**监测**衰减器/放大器的输出功率

---

## 3. EMGen (7003-003) - 信号发生器 🆕 可扩展

### 功能

#### 载波生成
- 频率范围: 100 kHz - 6 GHz（取决于型号）
- 功率控制: -50 dBm 到 +10 dBm
- 频率步进: 可配置

#### 调制功能
- **幅度调制（AM）**: 
  - 内部调制源
  - 外部调制源
  - 调制深度: 0-100%
- **频率调制（FM）**:
  - 频偏控制
  - 内部/外部调制源
- **脉冲调制（Pulse）**:
  - 脉宽控制
  - 脉冲重复频率

### 主要SCPI指令

| 指令 | 功能 | 页码 |
|------|------|------|
| `<S>:FREQ <Hz>` | 设置载波频率 | p.42 |
| `<S>:POWER <dBm>` | 设置输出功率 | p.48 |
| `<S>:OUTPUT ON/OFF` | 开关RF输出 | p.44 |
| `<S>:AM:STATE ON/OFF` |开关幅度调制 | p.36 |
| `<S>:FM:STATE ON/OFF` | 开关频率调制 | p.39 |

**EMCenter控制外部衰减器/放大器的可能性**: ❌  
- EMGen是**信号发生器**，用于产生RF信号
- 不能直接控制外部衰减器或放大器
- 但可通过调整输出功率模拟衰减效果

## 4. EMControl (7006-001) - 定位器/转台控制 🎯 重要发现！

### 功能

这是EMCenter中**唯一可能控制外部设备**的模块！

#### 支持的定位设备
- **转台（Turntable）**: 天线方向图测试用
- **塔架（Tower）**: 垂直定位控制
- **Reverberation Paddle**: 混响室搅拌器

#### 控制能力
- 位置控制（度数或厘米）
- 速度控制
- 加速度设置
- 运动方向控制
- 限位设置
- 循环扫描

### 主要SCPI指令

| 指令 | 功能 | 页码 |
|------|------|------|
| `<S>:CP?` | 查询当前位置（度/cm） | p.57 |
| `<S>:CP <pos>` | 改变当前位置 | p.57 |
| `<S>:SK <pos>` | 移动到目标位置 | p.64 |
| `<S>:SKN <pos>` | 逆时针移动到目标 | p.64 |
| `<S>:SKP <pos>` | 顺时针移动到目标 | p.65 |
| `<S>:S?` | 查询速度 | p.63 |
| `<S>:S <speed>` | 设置速度 | p.63 |
| `<S>:A?` | 查询加速度 | p.56 |
| `<S>:A <accel>` | 设置加速度 | p.56 |
| `<S>:DIR?` | 查询运动方向 | p.59 |
| `<S>:M?` | 查询马达状态 | p.60 |

### 🔌控制外部衰减器/放大器的可能性

**可能性分析**:

✅ **理论上可行** - 如果:
1. 外部衰减器/放大器配备了**马达驱动**（如步进电机控制的可变衰减器）
2. 通过EMControl的**马达控制接口**连接
3. 衰减器/放大器的转轴位置对应衰减值

❌ **实际限制**:
- EMControl主要为**旋转定位**设计（转台/天线塔架）
- 不是为衰减器/放大器专门设计
- 需要硬件改装才能适配

**更现实的方案**:
- 使用专用程控衰减器（如Weinschel/Mini-Circuits的USB/以太网控制型号）
- 使用专用程控放大器（自带SCPI接口）
- 通过EMCenter机箱的**空闲插槽**添加自定义控制卡

## 💡 EMCenter控制外部设备的能力总结

### ✅ 可以直接控制的设备

1. **射频开关** - 通过EMSwitch (7001-0xx) ✅ 已实现
2. **转台/定位器** - 通过EMControl (7006-001) 🆕 可实现
3. **信号发生器** - 通过EMGen (7003-003) 🆕 可实现

### ❌ 不能直接控制的设备

4. **程控衰减器** - 需要外部控制器或专用接口
5. **程控放大器** - 需要外部控制器或专用接口

### 🔧 替代方案

#### 方案A: 通过EMSwitch间接控制

如果衰减器/放大器有**继电器控制端口**:
- 使用EMSwitch的外部继电器接口
- 切换不同的固定衰减值（离散控制）
- 切换放大器开关（ON/OFF控制）

**限制**: 只能离散控制，不能连续调节

#### 方案B: 独立控制系统

使用专用程控衰减器/放大器（推荐）:
- **程控衰减器**: 
  - Mini-Circuits RCDAT系列（USB控制）
  - Weinschel 8310系列（GPIB/以太网）
- **程控放大器**:
  - Mini-Circuits ZVE系列（以太网控制）
  - Fairview Microwave可调增益放大器

在系统中添加独立驱动，与EMCenter并行控制。

#### 方案C: 定制EMCenter扩展卡（高级）

如果预算充足:
- 联系ETS-Lindgren开发定制7000系列插件卡
- 专门用于衰减器/放大器控制
- 集成到EMCenter机箱中
